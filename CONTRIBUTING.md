# Contributing

Start with the [roadmap](ROADMAP.md) and [acceptance scenarios](docs/ACCEPTANCE.md). Open a focused issue describing the supported behavior and expected result before proposing a broader integration.

Use synthetic fixtures and redact logs. Keep proposed permission changes separate from implementation changes. Document any unsupported cases and incomplete observations.

No open-source license or contributor agreement has been selected. Discuss contributions with the maintainer before submitting substantial code; do not assume public visibility grants reuse rights or specifies contribution licensing.
